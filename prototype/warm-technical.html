Batteries included

Real APIs, not a feature checklist.

Page routing

A page is an entity plus a route entry. Sidebar, ⌘K launcher and deep links all read the same registry.

Architecture docs
src/app/routes.rs
// register once — sidebar, ⌘K and deep links follow
pub fn routes(cx: &mut App) -> Vec<Route> {
    vec![
        Route::new(Page::Home).icon("house"),
        Route::new(Page::Form).icon("file-text"),
        Route::new(Page::Settings).icon("settings"),
        Route::new(Page::Diagnostics).dev_only(),
    ]
}

Fluent i18n

Built on es-fluent, so message keys are typed at compile time. Validation errors resolve through the same bundle.

i18n setup
i18n/en/app.ftlfluent
form-email-invalid = { $value } is not a valid email
update-available   = Version { $version } is ready

// src/pages/form.rs
label.child(t!(FormEmailInvalid { value: &input }))

Forms & validation

gpui-form binds inputs to a struct; koruma derives the rules. Messages come back localized, per field.

Forms guide
src/pages/form.rsrust
#[derive(Form, Validate)]
struct SignUp {
    #[validate(email)]
    email: String,
    #[validate(length(min = 8))]
    password: String,
    #[validate(url, optional)]
    website: Option<String>,
}

gpui-query

Cache policy per query, plus retries, invalidation and cancellation, all observable from an entity.

gpui-query docs
src/pages/home.rsrust
let projects = use_query(
    QueryKey::new("projects"),
    |_| async { api::projects().await },
    QueryOptions {
        cache: CachePolicy::StaleWhileRevalidate(60.secs()),
        retry: RetryPolicy::exponential(3),
        ..default()
    },
    cx,
);

Notifications

Native OS backend when available, in-app toast when not, and a persistent inbox the user can reopen.

Notifications docs
src/system/notify.rsrust
Notification::new("Export finished")
    .body("report.csv · 4.2 MB")
    .action("Reveal", Action::RevealInFinder(path))
    .fallback(Fallback::Toast)
    .send(cx);

// native → toast → inbox, in that order
